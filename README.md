# Student Restaurant Lookup

a web app that shows student restaurant menus in Finland

##

-Features-
- lists restaurants from metropolia api sorted alphabetically
- switch between daily and weekly menu
- weekly menu is grouped by weekday and if there is a empty day it will not be visible
- each dish has a visible name, diet restriction price
- user registration and login with the restaurant api
- responsive layout for phones (maybe)
